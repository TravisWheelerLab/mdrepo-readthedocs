# MDRepo TOML/Metadata Specification

Use the [metadata creation](https://mdrepo.org/metadata) form or the [mdr-meta](https://github.com/TravisWheelerLab/mdrepo-rs/releases) command-line tool to generate a valid TOML/metadata file or craft one by hand using the following description.

## Required Fields

A minimal [TOML](https://toml.io/en/) file must contain the following required fields:

* `lead_contributor_orcid`: The [ORCID](https://orcid.org/) (in the format _xxxx-xxxx-xxxx-xxxx_) of the contributor responsible for uploading the simulation.
* `trajectory_file_names` [array of text]: Trajectory files contain atomic coordinates of sequential snapshots of the simulation system. Examples of extensions of trajectory files generated by different popular MD simulation packages are GROMACS (_.xtc_/_.trr_), AMBER (_.netcdf_/_.crd_), CHARMM/NAMD (_.dcd_)
* `structure_file_name` [text]: A structure file contains the atomic coordinates of one snapshot of the simulation system. The most popular format is a PDB file. Examples of extensions of structure files, other than PDB formated, generated by different popular MD simulation packages are GROMACS (_.gro_), CHARMM (_.cor_).
* `topology_file_name` [text]: The topology file contains the parameters for how the atoms in the molecule interact with each other through bonded and non-bonded interactions, as well as any added constraints or exclusions. Examples of extensions of topology files generated by different popular MD simulation packages are GROMACS (_.top_/_.tpr_), AMBER (_parm*.dat_), CHARMM/NAMD (_.psf_).
* `temperature_kelvin` [integer]: The temperature of the simulation in the range 275-700 Kelvin.
* `integration_timestep_fs` [integer]: The integration time step used for the simulation in the range 1-20 fs
* `short_description` [text]: A short (300 characters) description of the simulation
* `software_name` [text]: Software name, e.g. ACEMD, AMBER, CHARMM, CUSTOM, GROMACS, NAMD, SPONGE
* `software_version` [text]: Software version (use "NA" for "CUSTOM" software)

## Optional Fields

The following fields are optional but users are _strongly encouraged_ to provide them, if applicable:

* `pdb_id` [text]: An associated Protein DataBank (PDB) ID
* `uniprot_ids` [array of text]: Associated Uniprot IDs

The following fields are entirely optional:

* `description` [text]: A longer description of the simulation
* `run_commands` [text]: The commands used to produce the simulation
* `dois` [array of text]: A list of digital object identifiers (DOI) (in leiu of `[[papers]]`)
* `collections` [array of text]: Named collections the simulation belongs to, e.g. `["ATLAS"]`
* `forcefield` [text]: Type of force field used to produce the simulation, e.g., AMBER, Amber ff99SB-ILDN, CHARMM36
* `forcefield_comments` [text]: Comments relating to the force field used, e.g., ligand parameters
* `protonation_method` [text]: The method used for adding the protonation state, e.g., PropKa, AutoDockFR, AutoDockFR
* `alias` [text]: A unique, user-assigned alias/accession for the simulation
* `sampling_frequency_ps` [floating-point number]: The simulated time between consecutive saved trajectory frames, in picoseconds (AMBER's `ntwx`, GROMACS's `nstxout`, times the integration timestep), in the range 1-100000. Read in two situations, and ignored otherwise. First, when the trajectory file itself carries no time axis (e.g., an AMBER NetCDF stripped of solvent by cpptraj, or an ASCII mdcrd) it supplies the spacing, since nothing can be measured. Second, when a spacing *was* measured and comes out below 10 ps, this value is **required** and must match what the trajectory reports: a file carrying no usable timing is stamped by the conversion with a default of 1 ps per frame, which is indistinguishable from a genuine 1 ps, so a spacing that small is not recorded on the trajectory's word alone. If your simulation really did save frames less than 10 ps apart, declare it here. At or above 10 ps the trajectory's own time axis is authoritative and this value is ignored.
    * **1 ps is an absolute minimum.** No spacing below it is accepted from any source, declared or measured.
    * **"Match" means within 1% of the value you declare.** The comparison is made in floating-point against the spacing measured from the trajectory, so declare the value your run actually used rather than a rounded one: a disagreement that looks like exactly 1% on paper can still fall outside the tolerance and be refused.
    * A declaration that contradicts the trajectory is rejected rather than believed. If the trajectory's own timing is the part that is wrong, the file needs correcting -- this field cannot stand in for it.
* `is_embargoed` [boolean]: Whether the simulation should be kept private (embargoed) rather than released publicly once approved. Defaults to `false` if omitted. Orthogonal to the approval process -- an embargoed simulation is hidden from public listings/downloads even after it is otherwise approved, until the embargo is lifted.

## Optional Tables

The following [TOML tables](https://toml.io/en/v1.1.0#table) are optional:

* `[water]` (may be omitted, but all fields required if present)
    * `model` [required, text]: Water model used for the simulation, e.g., TIP3P, TIP4P
    * `density_kg_m3` [required, floating-point number]: Water density in the simulation in the range 900-1100 kg/m3
* `[[additional_files]]` (can be repeated)
    * `file_name` [required, text]: File name
    * `file_type` [required, text]: Additional file type, e.g., Input, Structure, Trajectory, Topology, Periodic boundary condition, Restart, Logs, Checkpoint, Parameters, User defined file, Miscellaneous
    * `file_description` [optional, text]: Comments or description of the file
* `[[ligands]]` (can be repeated)
    * `name` [required, text]: Name of the ligand
    * `smiles` [text]: SMILES string for the ligand. Required unless you give `inchi` instead.
    * `inchi` [text]: Standard InChI string for the ligand, e.g. `InChI=1S/CH4/h1H4`. Required unless you give `smiles` instead. Must be a *standard* InChI -- one beginning `InChI=1S/`; the non-standard `InChI=1/` form is refused, because two non-standard InChIs are not comparable and comparability is the whole reason for accepting the notation.
    * **At least one of `smiles` and `inchi` is required, and either one alone is enough.** Whichever you leave out is derived from the one you gave and stored beside it. Give both and both are kept, and checked against each other: a pair describing two different molecules is refused rather than guessed at. Neither value is ever rewritten in your own file.
        * A SMILES derived from an InChI will not be the string you would have written. SMILES has no canonical form, so the atom ordering and ring numbering come from the conversion; the molecule is the same one, and the InChIKey is what identifies it.
        * **If you validate with `mdr-meta`,** note that releases up to and including v0.3.23 require `smiles` and reject a ligand declared only by `inchi`, even though the archive itself accepts it. Give `smiles` as well, or use a later release.
* `[[solutes]]` (can be repeated)
    * `name` [required, text]: Solute name, e.g., Cl-, K+, Na+, Phosphoric acid, Urea,
    * `concentration_mol_liter` [required, floating-point number]: Solute concentration in the range 0-1 mol/liter
* `[[papers]]` (can be repeated, or use dois)
    * `title` [required, text]: Paper title
    * `authors` [required, text]: Paper authors
    * `journal` [required, text]: Paper journal
    * `year` [required, integer]: Paper published year
    * `volume` [required, integer]: Paper volume
    * `number` [optional, text]: Paper number
    * `pages` [optional, text]: Paper pages
    * `doi` [optional, text]: Paper DOI
* `[[external_links]]` (can be repeated)
    * `url` [required, text]: A URL
    * `label` [optional, text]: The label to display
* `[[contributors]]` (can be repeated)
    * `name` [required, text]: Name of the contributor
    * `orcid` [optional, text]: ORCID of the contributor
    * `email` [optional, text]: Email address of the contributor
    * `institution` [optional, text]: Institution of the contributor
